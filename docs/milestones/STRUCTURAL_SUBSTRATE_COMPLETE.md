# Architectural Principles

Each layer has a single responsibility.

Each layer remains independently inspectable.

Each layer remains independently testable.

Each layer extends rather than replaces the previous layer.

No layer establishes:

- truth
- authority
- causation
- correctness
- proof

The Structural Substrate preserves observable structure only.
