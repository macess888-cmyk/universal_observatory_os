# Purpose

The Explorer provides a human-centered interface for navigating observable structures.

Unlike validators and inspection services, the Explorer does not create new observations.

It enables people to navigate, inspect, and understand existing observable structures.

---

# Explorer Responsibilities

The Explorer helps users:

- discover observable formations
- inspect observable reports
- navigate observable relationships
- explore timelines
- visualize graph structure
- preserve unknowns
- identify future inspection targets

---

# Explorer Does Not

The Explorer does not:

- establish truth
- replace judgment
- make decisions
- infer causation
- predict outcomes

Its purpose is exploration.

---

# Explorer Architecture

```text
Observables

↓

Validators

↓

Inspection

↓

Reports

↓

Explorer
```

The Explorer consumes preserved reports.

It never bypasses inspection.

---

# Guiding Principle

The Explorer should help people ask better questions.

It should not answer questions that evidence has not earned.
